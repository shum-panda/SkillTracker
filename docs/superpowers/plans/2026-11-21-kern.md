# SkillTracker Kern – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA, die einen englischen Text (Foto oder getippt) mit eigener KI einliest und bewertet, sechs Achsen als Spinnennetz zeigt und einen Verlauf führt – alles lokal im Browser.

**Architecture:** Statische Seite unter `app/` aus ES-Modulen ohne Build. `app/core/` ist reine Logik (läuft in Node und Browser, getestet mit `node --test`), `app/ui/` ist DOM-Code. KI-Aufrufe gehen direkt per `fetch` an den gewählten Anbieter; Daten liegen in IndexedDB.

**Tech Stack:** HTML/CSS/JS (ES2022-Module), IndexedDB, Service Worker, Node 20 `node:test` für Tests, Python 3.11 + `wordfreq` nur für das einmalige Exportskript.

**Spec:** `docs/superpowers/specs/2026-11-21-kern-design.md`

## Global Constraints

- Keine Laufzeit-Abhängigkeiten, kein Build-Schritt; `app/` ist direkt auslieferbar.
- `app/core/**` importiert nichts aus dem DOM (`document`, `window`, `indexedDB` nur in `app/ui/**` bzw. `core/store-idb.js`).
- Oberfläche Deutsch; KI-Erklärungen Deutsch; Korrekturen/verbesserte Fassung Englisch.
- Claude-Kopfzeilen: `x-api-key`, `anthropic-version: 2026-10-21`, `anthropic-dangerous-direct-browser-access: true`; Standardmodell `claude-opus-5-5`, `output_config.effort: "low"`; Fallback-Beta `server-side-fallback-2026-07-01` + `fallbacks: "default"` nur für `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-fable-5-1`.
- Achsen-Formeln exakt wie in der Spec (Grammatik `100·e^(−d/8)`, Satzbau `100·e^(−d/4)`, Vielfalt `clamp((MTLD−30)/80·100)`, Niveau `clamp(Anteil/0,15·100)` mit Zipf < 4,5, Komplexität `clamp(0,5·(L−6)/16·100 + 0,5·S/1,2·100)`); Mindestlänge 10 Wörter, Hinweis unter 50.
- Jede Einfügung fremder Strings ins HTML über `esc()`; Links nur `https:`.
- Schlüssel gehen nur an den Anbieter, zu dem sie gehören; Export ohne Schlüssel, außer ausdrücklich gewählt.
- Zeilenenden LF (`.gitattributes`).
- Commit-Trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` und `Claude-Session: https://claude.ai/code/session_01HLVVxRuRYBeNgNmm2DuYLA`.

## Review Focus

1. KI-Antwort mit gültigem JSON, aber falschen Typen/unbekannter Kategorie/`quote`, das nicht im Text steht → zweiter Versuch bzw. Fehler ohne Markierung, nie Absturz oder kaputte Markierung (Tests in Task 4/5/6).
2. Fehler-Zitate, die mehrfach oder überlappend im Text vorkommen → Markierung der Reihe nach, keine Überlappungen (Task 5).
3. Sehr kurze Texte, Texte nur aus Zahlen/Satzzeichen, deutsche Wörter dazwischen → keine `NaN`, keine Division durch 0 (Task 3/5).
4. Import einer fremden/kaputten Datei und HTML/Skript in KI-Antworten → kein Einschleusen (Task 7/9).
5. Anbieter-Fehler (401, 404, 429, Netzfehler, Abbruch, `refusal`, kompatibler Server ohne `json_schema`) → verständliche deutsche Meldung, eingegebener Text bleibt (Task 6/10).

### Task 3: Text-Metriken

**Files:** Create `app/core/text.js`, `app/core/metrics.js`, `tests/metrics.test.mjs`.

**Interfaces:**
- `tokenize(text) -> string[]` (Regex aus Spec, klein, `’`→`'`).
- `splitSentences(text) -> string[]` (an `.!?` gefolgt von Leerraum/Ende; nicht nach `e.g. i.e. mr. mrs. ms. dr. etc. vs.`; leere entfernt).
- `mtld(tokens, threshold = 0.72) -> number` (vorwärts/rückwärts gemittelt; Rest-Faktor anteilig; `tokens.length === 0` → 0).
- `levelShare(tokens, freqMap) -> {share, counted}` (Anteil Zipf < 4.5 unter Wörtern, die in der Liste stehen).
- `complexity(text) -> {avgLen, subPerSentence, sentences}`; Signalwörter: `because although though which who whom whose when while if unless since whereas until that whether wherever whenever`.
- `computeMetrics(text, freqMap) -> {words, sentences, mtld, levelShare, levelCounted, avgLen, subPerSentence}`.

- [ ] Tests: `tokenize("I don’t know, Mr. Smith!")` → `["i","don't","know","mr","smith"]`; `splitSentences("I went home. Mr. Lee was there! Was he?")` → 3 Sätze; `mtld` einer Folge aus 100 gleichen Wörtern < 5, aus 100 verschiedenen Wörtern = 100 (keine Faktoren → Länge/1 nach Formel mit Rest-Faktor); `levelShare` mit Testliste; `complexity("I stayed because it rained. It was cold.")` → `avgLen 4`, `subPerSentence 0.5`; leerer Text → alles 0, kein `NaN`.
